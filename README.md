# PMWEB 项目管理工具

PMWEB 是一个轻量级、面向单用户的本地优先网页项目管理应用。纯前端运行，无需后端服务，支持多项目组织、任务树与可配置列、甘特图与日历可视化、法定节假日标识、持久回收站以及包含附件二进制的完整备份与恢复。

## 核心功能与使用指南

### 1. 本地存储架构

* **工作区存储**：项目元数据、任务数据、列配置、工作日历规则与回收站记录均保存在浏览器的 LocalStorage 中（数据结构遵循 v4 工作区标准）。
* **附件持久化**：任务关联的附件文件与协同文件以原始二进制形式存放在浏览器的 IndexedDB 中，元数据与实体内容分离解耦，保障大文件存储稳定性。
* **数据主权**：所有业务操作均在本地浏览器环境完成，不向任何未授权第三方服务器自动上传用户数据。

### 2. 项目选择与启动偏好

* **多项目管理**：支持创建多个独立项目，各项目间的任务、自定义列配置、状态筛选与视图偏好相互完全隔离。
* **启动模式**：通过菜单可自由配置应用启动偏好：
  * **每次启动手动选择**（choose）：打开应用时展示项目选择引导层。
  * **恢复上次打开项目**（last）：启动时自动激活最近一次使用的项目。
  * **固定默认项目**（fixed）：指定特定项目作为启动默认激活项。
* **容错回退**：当配置的固定默认项目被删除或归档后，应用安全回退至项目选择界面，避免空白报错。

### 3. 项目归档与持久回收站

* **项目收尾与归档**：支持将已结项项目标记为归档。归档项目自动从日常活跃项目列表中移出；提供归档项目只读查阅入口，支持随时重新激活恢复。
* **任务删除与两级保护**：删除任务及其子任务、依赖关系与附件后，数据首先进入回收站，支持跨会话浏览、查看关联元数据及一键还原。
* **永久删除安全机制**：在回收站中执行永久删除需要显式二次确认。系统具备引用计数保护，若底层附件 Blob 仍被其他活跃项目或活动记录引用，绝不误删共享实体。

### 4. 四种视图开关与灵活布局

* **主工作台双开关**：工具栏提供独立的「甘特图」与「日历」两个视图开关按钮，按钮状态与实际显示严格同步：
  * **仅开启甘特图**：左侧为任务表格，右侧为甘特图时间轴，任务行与时间轴保持像素级垂直滚动同步与对齐。
  * **仅开启日历**：左侧为任务表格，右侧为月度日历视图。
  * **两者同时开启**：左侧为任务表格，右侧垂直切分为上方甘特图与下方日历，甘特图与表格联动，日历独立导航。
  * **两者同时关闭**：任务表格自动横向铺满全部可用工作区宽度，提供大屏表格沉浸式查看。
* **今日节点独立面板**：独立开关控制今日关键里程碑面板。在桌面宽屏时停靠于右侧侧边栏，在窄屏移动端下自动折叠下沉至底部，不干扰主视图操作。
* **时间轴缩放**：甘特图支持日、周、月三种时间粒度平滑加减缩放，缩放时智能保持当前查看日期居中，不改变任务既定起止日期。

### 5. 列配置与自定义字段

* **列配置独立外置**：工具栏设置直达当前项目列管理弹窗。
* **灵活定制**：内置列支持重命名与显隐切换；支持添加文本、数字、日期、单选四种类型的自定义字段；支持拖拽排序与键盘排序；支持全部隐藏安全恢复。每个项目的列配置完全独立，互不影响。

### 6. 工作日历与节假日标识

* **法定节假日订阅**：内置中国法定节假日与调休补班数据源，支持在线订阅与离线缓存。
* **仅作视觉标识**：节假日与补班在日历与时间轴上作为参考背景标识展示，不强制自动篡改用户的任务工期与排期。
* **支持灵活覆盖**：支持用户针对具体项目自定义工作日例外规则，支持导入年度自定义 JSON 节假日配置。

### 7. 完整备份与恢复

* **完整数据备份包**：导出功能生成标准 JSON 备份文件，包含所有项目、活跃任务、归档项目、回收站记录、列配置、工作日历以及经 Base64 编码的全部附件二进制内容。
* **事务级安全恢复**：导入备份文件时，系统先执行格式与版本完整性预检；在确认写入前不对现有存储进行任何修改；解析损坏、更高版本或存储超限时完整回滚，坚决防止损坏现有数据。

## 使用限制与边界说明

1. **单用户单端运行**：本项目定位为单用户本地轻量应用，不包含云端多用户实时协同、服务端冲突自动合并或账号权限管理功能。
2. **浏览器存储容量限制**：数据持久化依赖宿主浏览器的 LocalStorage 与 IndexedDB 配额。当本地磁盘空间不足或触发浏览器沙箱配额时，将无法写入新文件。建议定期使用「完整备份」功能导出归档文件。
3. **同源策略限制**：在部分浏览器中直接以 `file://` 协议打开本地 HTML 文件时，因跨源资源共享（CORS）与本地文件沙箱安全策略限制，法定节假日外部远程订阅可能无法联网更新，此时系统将自动回退使用内置离线日历规则。
4. **项目间依赖隔离**：任务前置依赖与层级关系仅限定在当前项目内部建立，不支持跨项目建立关联链接。

## 快速上手与构建

### 运行方式

直接在现代浏览器（Chrome、Edge、Safari、Firefox）中打开 `dist/index.html` 单文件即可完整使用。

```bash
# 方式一：直接在浏览器中打开构建产物
open dist/index.html

# 方式二：使用本地静态服务器预览
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/dist/index.html
```

### 构建与测试

项目不依赖 npm 安装外部构建工具，使用 Node.js 原生脚本执行打包与测试：

```bash
# 执行单文件打包构建（生成 dist/index.html 并复制 favicon.svg）
node build.js

# 运行全量单元测试与回归套件
node tests/run-all.js

# 运行构建产物验证与冒烟测试
node tests/build.test.js
node tests/smoke.test.js
```
