# P3-2 审计日志、只读分享与打印视图设计

## 1. 结论

P3-2 交付三项能力：
1. 服务端追加式审计日志集合与前端审计查询视图。
2. 基于高熵令牌与哈希校验的项目级只读分享链接。
3. 专用打印样式与 PDF 导出支持。

## 2. 审计日志设计

### 2.1 数据模型
服务端集合为 `audit_log`：
- `project`：关联项目，级联删除。
- `actor`：操作人（用户集合关系）。
- `actor_name`：操作人显示名。
- `action`：动作类型（`create`、`update`、`delete`、`restore`）。
- `entity_type`：实体类型（`tasks`、`milestones`、`links` 等）。
- `entity_id`：业务实体 ID。
- `before_json`：变更前数据快照。
- `after_json`：变更后数据快照。
- `at`：变更发生时间戳。

### 2.2 安全与防篡改
- 客户端无直接创建、修改或删除权限（API 规则设为 null）。
- 记录由服务端在写事务中生成。
- 项目成员具备列表与详情只读权限。

## 3. 只读分享设计

### 3.1 令牌与哈希
- 生成高熵随机令牌（例如 32 位随机十六进制字符串）。
- 服务端集合 `share_links` 仅存储该令牌的 SHA-256 哈希值与元数据（过期时间、撤销时间、创建人）。
- 分享 URL 携带原令牌（如 `?share=token`）。
- 验证时对比哈希，避免数据库泄露明文令牌。

### 3.2 只读模式界面受限
当处于只读模式（携带有效分享参数或 `?readonly=1`）时：
- 隐藏或禁用所有写入口：新建任务、导入数据、设置工作日历、修改列配置、添加依赖等。
- 禁用表格单元格双击行内编辑，禁用时间轴任务条拖拽。
- 页面顶部展示只读提醒横幅，并提供一键打印按钮。

## 4. 打印与 PDF 视图

- 提供专用打印样式 `@media print`。
- 打印时自动隐藏工具栏、状态栏、侧边待办、分割条等干扰元素。
- 表格与时间轴自动消除滚动条与高度限制，完整平铺打印。
- 避免任务行内分页断裂。
